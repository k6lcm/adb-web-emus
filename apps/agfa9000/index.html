About Agfa 9000PS Web Emulator

Full-system Motorola 68020 + VERA emulator compiled to WebAssembly

Emulates the repurposed Agfa Compugraphic 9000PS PostScript RIP main board running AGFA-MON, CP/M-68K v1.6, and Minix 2.0.4, complete with the Commander X16 VERA video/audio module installed in the VIA #2 socket.

  • CPU: Motorola 68020 @ 16 MHz (Musashi core + SoftFloat)
  • ROM: 384 KiB across 12 split 27C256 EPROMs (AGFA-MON + EhBASIC, CP/M-68K, Minix 2.0.4)
  • Storage: NCR AM5380 SCSI controller + 171 MiB disk image with IndexedDB copy-on-write persistence
  • Serial: Zilog Z8530 SCC connected to xterm.js
  • Video & Audio: VERA 640×480 256-color display + 16-ch PSG & PCM stereo audio
Upstream emulator: fletto2/agfa_emus
