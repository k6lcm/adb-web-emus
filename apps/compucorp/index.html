Compucorp 665 Web Emulator & Reference

2.6624 MHz Z80 · Paged/MEX RAM · 80×20 / 80×60 CRT · Floppies & Flux (.img/.cc665/.hfe/.scp) · Hard Disks

Hardware-level emulator for the Compucorp 665 running ZEBRA 7/8, Omega, standalone hardware diagnostics, and open-source xcpmz80, compiled from the C reference core to WebAssembly. Supports classic paged memory (-m), ZEBRA 8 MEX boards (-e), 60-line CRT card (-X), US & Metric 85 glyph PROMs, PB5/JT1 ROM-off mods, Winchester & 691 hard disks, Centronics & SIO B Diablo 630 printers, and raw/container/flux floppy images (.img, .cc665, .hfe, .scp). Use Save As on any drive card to download .img (or Shift+Click for self-contained .cc665).

Quick Start: Open Library to boot open-source xcpmz80 (automatically enables PB5 ROM-off & xcpmz80 keyboard layout), run the Hardware Diagnostics suite, or mount local Omega/ZEBRA .img/.cc665/.hfe/.scp images. Toggle Fast (Alt+F or ScrollLock) for instant disk booting.
